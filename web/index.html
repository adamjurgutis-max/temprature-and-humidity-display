ESP32 Temperature & Humidity Monitor

Firmware for ESP32 DevKit V1, DHT22 and a 0.91-inch 128×32 SSD1306 I²C OLED.

Before flashing
  1. Use Google Chrome or Microsoft Edge on a computer.
  2. Connect the ESP32 to USB.
  3. Close other tabs or programs using its serial port.
  4. Click Install and select the ESP32 serial port.

Important: Flashing erases the current program on the ESP32. The OLED and sensor should be wired as described in the project instructions.
